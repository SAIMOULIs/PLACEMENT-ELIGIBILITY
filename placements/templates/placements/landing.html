Access

🏫 Placement Officer

Placement Officer access is not self-authorized. Submit an access request with institution and designation details. An Administrator reviews the request before activating the account.

Request Officer Access

🔐 Administrator

The Administrator is the Django superuser created with createsuperuser. Administrators approve or reject officer access requests.

Admin Login

Student records are managed by the Placement Officer through the placement database and Excel/CSV import. Students are not required to create website accounts.
